关于

我是 AlexYang。这个博客是我的笔记本，不是媒体。

写下来的东西，大多是我自己先没搞明白、后来搞明白了的， 或者是绕了远路才走通的。如果你也正好卡在某个地方， 希望这里能帮你省一点时间。

不追热点，写得慢。写不出清楚的东西时，就不写。

在做什么

  • 在写 技术笔记、踩坑记录、偶尔一些没想清楚的想法
  • 在折腾 自建服务、内网穿透、Minecraft 服务器
  • GitHub github.com/Weiheyi

这个博客是怎么搭的

没有用博客框架，也没装任何依赖。就是几个静态文件： HTML 写结构、一份 CSS 管样式、一小段 JavaScript 在浏览器里把 Markdown 渲染成文章。加起来不到 30KB，打开就是最终内容。

这么做的好处是：放哪都能跑。GitHub Pages、Netlify、自己的服务器， 甚至直接双击 index.html 都能看（本地预览需要一个小服务器， 因为浏览器禁止从 file:// 读文件）。

写一篇新文章的流程只有两步：在 posts/ 里新建一个 .md 文件，再到 posts.json 里加一条记录。 没有构建步骤，没有等待。
